# 📚 E-Boimela – A Modern E-Library Platform

**E-Boimela** is a complete, modern, and fully responsive **e-library web platform** built with **React.js** and **Tailwind CSS**.  
It allows users to explore, search, read, and manage books easily across all devices with a smooth and user-friendly experience.

## 🌐 Live Website: https://e-boimela-book-shop.vercel.app/


## 🎯 Project Purpose

This project demonstrates:
- Strong frontend architecture  
- Real-world UI/UX implementation  
- State persistence using localStorage  
- Clean component structure  
- Modern React development practices  


## 🚀 Project Overview

E-Boimela is designed to simulate a real-world digital library system where users can:
- Browse books by genres, authors, and publishers  
- Search books using multiple filters  
- Add books to cart and manage purchases  
- Instantly read or download free books  
- Experience smooth UI interactions with persistent state using `localStorage`

The platform focuses on **performance, usability, and responsiveness**.


## ✨ Key Features

### 📱 Responsive Navigation System
- Fully responsive navigation bar for all screen sizes  
- Mobile-friendly menu bar  
- Right-side slide-in menu for small devices  


### 🎨 Theme Management (Dark & Light Mode)
- Fully implemented **Dark / Light theme**  
- Theme preference stored in **localStorage**  
- Theme remains unchanged after page refresh  


### 📖 Book Details & Reading Experience
- Clicking any book card opens a **details page**  
- If the book price is **৳0 (Free)**:
  - No need to add to cart  
  - Users can **directly download and read** the book  


### 🛒 Book Cart System
- Add books to cart functionality  
- Cart data stored in **localStorage**  
- Persistent cart state even after refresh  


### 🔍 Advanced Search Functionality
Search books dynamically based on:
- 📖 Book Title  
- 🏷️ Category / Genre  
- ✍️ Author  
- 🏢 Publisher  

All results are displayed accurately in real-time.


### 🏠 Home Page Highlights
- Modern hero/banner design  
- Displays:
  - ⭐ Number of Reviews  
  - 👥 Number of Installers  
  - 📚 Total Number of Books  
- Counters dynamically update and refresh properly  


### 🧩 Genres Page
- Displays **all unique genres** in a card layout  
- Each genre card shows:
  - Genre name  
  - Total number of books  
- Clicking a genre card shows **all books under that genre**


### ✍️ Author Page
- Displays **unique authors** in card format  
- Shows total books per author  
- Clicking an author reveals all related books  


### 🏢 Publisher Page
- Displays **unique publishers**  
- Shows number of books published by each  
- Clicking a publisher card shows all associated books  


### 💳 Recharge Page
- Guides users on how to **recharge balance**  
- Explains the account top-up process clearly  


### 🔁 Refund Policy Page
- Detailed refund policy explanation  
- Describes:
  - How users can return books  
  - Refund eligibility and process  


### ⬆️ Go-To-Top Scroll Feature
- Scroll-to-top floating button  
- Appears when user scrolls down  
- Smooth bounce animation  
- Positioned at the **bottom-right corner**  


## 🛠️ Technologies Used

- ⚛️ React.js  
- 🎨 Tailwind CSS  
- 🗂️ LocalStorage  
- 🌐 React Router DOM  
- 📦 Component-Based Architecture
